# Retained Esmeralda checkpoint transport

These files are unmodified JSON responses retrieved from the official Esmeralda indexer endpoint
on 2026-10-23. They are **untrusted transport**, retained so the v0.47 adapter can reproduce its
cryptographic verification relative to a separately reviewed release-derived candidate anchor.

They are not a trusted root, an approval record, or authorization evidence. The companion policy
and verification-results documents record the source URLs, SHA-256 digests, and verification
outcome.
