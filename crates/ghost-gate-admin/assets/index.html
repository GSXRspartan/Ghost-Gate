The control plane owns gate policy. Visitors cannot change anything here: every write is authenticated, CSRF-checked and audited.

First run — register the administrator

Paste the bootstrap token the admin server printed on first start (also on disk as bootstrap.token). It is void once one administrator exists.

Sign the challenge with your wallet's spend key (Ristretto). Provide the public key hex, the nonce and the signature — the server verifies them with the same machinery the gate-credential flow uses.
