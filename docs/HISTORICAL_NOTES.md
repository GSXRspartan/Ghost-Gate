# Historical Notes

This repository contains design investigations, localnet experiments, prior Crypt revisions,
security reviews, and screenshot evidence produced during development. They are retained for
provenance and audit context, not as the current release contract.

The current public-release description is the top-level README plus `ARCHITECTURE.md`,
`SECURITY.md`, `TELEGRAM.md`, and `DEMO.md`. In particular, documents referring to Crypt v2,
local-only URLs, prior consensus-flow claims, old Telegram fixtures, workers.dev origins, or earlier
deployment states are historical unless they explicitly identify Crypt v3 at `https://ghostgate.boo`.

Media in `docs/screenshots/` depicts earlier local/demo interfaces and is not used as current Crypt
v3 product material. Current release screenshots will be selected separately.
