# Contest Demo: Ghost Gate Privacy Lab

1. Open [ghostgate.boo](https://ghostgate.boo).
2. Select the **Crypt** gate and connect a supported wallet.
3. Review the active policy: 100 tTARI on Esmeralda testnet, Crypt v3 credential mode.
4. Complete the wallet's qualifying-output proof.
5. Confirm the seven-day verified session in the simple or technical view.
6. Optionally use `@GhostGateGSXRBot`, send `/join`, complete the same proof, and submit the
   matching Telegram join request.

The demonstration proves a configured minimum floor without displaying the total wallet balance or
the amount above the floor. It currently uses a revealed/public qualifying tTARI output and is an
operator-trusted testnet demonstration, not production authorization infrastructure.
