03Protocol compatibility

Changes between this build's Ootle cohort (v0.42.0) and the latest release (v0.52.0, 2026-11-09). Only the marked rows require Ghost Gate code changes.

  • v0.48 — transactions moved to sr25519 signing. affects the wallet signing path
  • v0.49 — fleet-wide reset; Esmeralda L2 state wiped. testnet gate must be re-published
  • v0.50 — template definitions moved to V2; mainnet settings ship in the binary. template rebuild under review
  • v0.51 — fee_claim_public_key and walletd permission changes. affects the walletd client
  • v0.52 — ClaimBurn yields a revealed TARI bucket. no effect — Ghost Gate does not use ClaimBurn

04What is blocking admission

Open implementation work, not accepted limitations.

  • Mainnet TARI resource address — not published. An Esmeralda address must never be substituted.
  • Cohort upgrade v0.42 → v0.52 — sr25519 signing and template V2 are breaking.
  • Mainnet indexer endpoint — not published; the SDK's default throws for mainnet.
  • Telegram identity binding — bot-to-bridge transport, durable receipts and admin isolation.
  • End-to-end admission test — required against real mainnet evidence before activation.
